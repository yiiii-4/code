# MC2 同传(interpreter)· 训练指南(阶段 A:数据 → 训练 → 合并)

目标:用你自己的 **4060(8GB 显存)** 本地微调 **Qwen3-4B-Instruct-2507**,得到一个中英互译模型,之后本地免费推理,配合 MC2 耳机做"听懂对方"的同传。

## 总览

```
1. 下载数据   scripts\prepare_translate_data.py   →  LLaMA-Factory/data/mc2_interpreter.json
2. 训练       llamafactory-cli train configs\train_qwen3_4b.yaml
3. 合并       llamafactory-cli export configs\export_merge.yaml  →  models/qwen3-4b-translate/
4. 试效果     llamafactory-cli chat configs\chat_test.yaml
5. (阶段 B)   FastAPI 推理服务 + 手机网页 + MC2  →  见「阶段B使用说明.md」
```

## 准备(每次开 PowerShell 先做)

```powershell
cd "G:\Gesture Analysis\llm_practice_project"
. .\mc2-interpreter\scripts\set_env.ps1   # 激活 venv + 把所有模型+缓存重定向到 G 盘(C 盘不落缓存)
```

> **为什么要跑 set_env.ps1**:①它把 venv 激活(这个 venv 没有自带的 `Activate.ps1`,所以脚本里直接加 PATH 等价激活);②把 Qwen3-4B 基座模型(约 8GB)、训练数据集、pip 缓存、torch 缓存全部重定向到 `G:\Gesture Analysis\llm_practice_project\` 下的 `.hf_cache / .pipcache / .torch_cache / .tmp`,C 盘不落缓存。**注意点号 `.` 不能少**(点源执行,变量才对当前窗口生效);关掉 PowerShell 就失效,下次开窗口再跑一次。

## 步骤 1:下载训练数据

```powershell
cd mc2-interpreter

# 先试跑:5000 句对 → 1 万条样本,几分钟,验证全链路
python scripts\prepare_translate_data.py --max_pairs 5000

# 看前 20 条预览,确认格式和句子质量
notepad ..\LLaMA-Factory\data\mc2_interpreter_sample.json
```

格式没问题就正式跑:

```powershell
python scripts\prepare_translate_data.py --max_pairs 10000    # 生成 2 万条样本
```

## 步骤 2:训练(QLoRA,本地 8GB)

```powershell
cd ..\LLaMA-Factory
llamafactory-cli train ..\mc2-interpreter\configs\train_qwen3_4b.yaml
```

说明:

- 首次会自动下载 Qwen3-4B-Instruct-2507(约 8GB,走 hf-mirror)。
- 2 万样本 × 2 轮,4060 笔记本约 **1.5–3 小时**,挂机跑、期间别打游戏。
- **报 OOM(显存不足)** → 把 `train_qwen3_4b.yaml` 里 `per_device_train_batch_size: 4` 改成 `2`。
- 损失曲线在 `saves/qwen3-4b/lora/translate/training_loss.png`;训练顺利的话 loss 会从 2.x 降到 1.x 以下。
- 中途断了想接着练 → 在 yaml 里加一行 `resume_from_checkpoint: saves/qwen3-4b/lora/translate`。

## 步骤 3:合并 LoRA → 完整模型

```powershell
llamafactory-cli export ..\mc2-interpreter\configs\export_merge.yaml
```

合并结果在 `models/qwen3-4b-translate/`(完整 HF 模型,阶段 B 推理直接加载它)。

## 步骤 4:先验一下翻译效果

```powershell
llamafactory-cli chat ..\mc2-interpreter\configs\chat_test.yaml
```

进去后输入:

```
把下面的中文翻译成英语,只输出译文。
今天天气不错,我们去散步吧。
```

看到译文正常,就说明模型练成了。

## 下一步:阶段 B(本地推理)

模型合并好后,按 **`阶段B使用说明.md`** 启动本地推理服务:

- **FastAPI 服务**:Whisper 识别(对方说英文→文字)→ 加载你的微调模型翻译成中文 → edge-tts/系统 TTS 双模式读出来
- **手机网页**:对方说话 → 手机收音 → 发 PC → 译文播进你戴的 MC2 耳朵
